# brand/

A verbatim copy of smaltui's assets from [stenhoor/smalt-brand](https://github.com/stenhoor/smalt-brand/tree/d9b0097404a978345706f6bc842d143524439e55) at `d9b0097`.
Don't edit these files: change them in smalt-brand, then run `npm run brand:sync -- --ref <commit>`.
CI runs `node scripts/sync-brand.mjs --check` to keep the copy exact.
