# brand/

A verbatim copy of smaltui's assets from [stenhoor/smalt-brand](https://github.com/stenhoor/smalt-brand/tree/bda2601af8342ba33ffdcd1779ab307296223879) at `bda2601`.
Don't edit these files: change them in smalt-brand, then run `npm run brand:sync -- --ref <commit>`.
CI runs `node scripts/sync-brand.mjs --check` to keep the copy exact.
