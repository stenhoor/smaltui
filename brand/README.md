# brand/

A verbatim copy of smaltui's assets from [stenhoor/smalt-brand](https://github.com/stenhoor/smalt-brand/tree/caa7984b9dc18905fa99357c556df55d304e490d) at `caa7984`.
Don't edit these files: change them in smalt-brand, then run `npm run brand:sync -- --ref <commit>`.
CI runs `node scripts/sync-brand.mjs --check` to keep the copy exact.
