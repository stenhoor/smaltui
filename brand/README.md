# brand/

A verbatim copy of smaltui's assets from [stenhoor/smalt-brand](https://github.com/stenhoor/smalt-brand/tree/c4f4bd382346d6c43f27a549f5cd8eef8219618b) at `c4f4bd3`.
Don't edit these files: change them in smalt-brand, then run `npm run brand:sync -- --ref <commit>`.
CI runs `node scripts/sync-brand.mjs --check` to keep the copy exact.
