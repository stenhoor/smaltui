# brand/

A verbatim copy of smaltui's assets from [stenhoor/smalt-brand](https://github.com/stenhoor/smalt-brand/tree/f1f65a979901d555ab9f4a448b17f6dba79c3fed) at `f1f65a9`.
Don't edit these files: change them in smalt-brand, then run `npm run brand:sync -- --ref <commit>`.
CI runs `node scripts/sync-brand.mjs --check` to keep the copy exact.
