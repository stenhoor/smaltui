# Keyboard shortcuts

On a Mac, <kbd>⌘</kbd> works where <kbd>Ctrl</kbd> is written. **⋯ → Keyboard shortcuts** lists them in the workbench.

## Editors

| Keys | In SQL tabs | In TypeScript tabs | In Cypher tabs |
| --- | --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Run the statement at the cursor, or the selection | Run the tab | Run the statement at the cursor, or the selection |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd>, <kbd>F5</kbd> | Run every statement | | Run every statement |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Explain the statement | Explain the tab's frame | Explain the statement |
| <kbd>Esc</kbd> | Cancel the running statement | Cancel the running query | |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | Complete keywords, functions, tables and columns | Complete smaltdf's functions, methods, tables and columns | Complete keywords, labels, relationship types and property keys |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Format the SQL | Re-indent the code | |
| <kbd>Ctrl</kbd>+<kbd>/</kbd> | Toggle line comments | | |
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | Indent, outdent | | |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save as a `.sql` file | Save as a `.ts` file | Save as a `.cypher` file |

## Workbench

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | A new query tab |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | Open a database |
| <kbd>Alt</kbd>+<kbd>W</kbd> | Close the tab |
| <kbd>Alt</kbd>+<kbd>←</kbd>, <kbd>Alt</kbd>+<kbd>→</kbd> | The previous or next tab |

## Grids

| Keys | Does |
| --- | --- |
| Arrows, <kbd>PgUp</kbd>, <kbd>PgDn</kbd> | Move between cells |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the cell |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy the row |
| <kbd>Enter</kbd>, double-click | Edit the cell (tables with a primary key), or see the whole value |
| <kbd>Ctrl</kbd>+<kbd>Delete</kbd> while editing | Set the cell to NULL |
